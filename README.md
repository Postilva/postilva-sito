# postilva.it

Il sito dell'associazione Postilva (Taranto), già costruito: pagine statiche pubblicate su Vercel.

**Non si modifica qui.** I testi e il generatore stanno nel repository di lavoro dell'associazione (`sito/associazione/`): si rigenera con `python3 costruisci.py && python3 pagine.py` e si copia qui il contenuto di `dist/`. Vercel ripubblica a ogni push su `main`.

Foto: Wikimedia Commons, con autore e licenza nelle didascalie. Caratteri: Space Grotesk e IBM Plex Mono, licenza SIL OFL (testi in `font/`).
